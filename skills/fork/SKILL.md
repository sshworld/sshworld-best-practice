현재 진행 중인 작업을 격리된 컨텍스트에서 끝까지 수행하라.

이 스킬은 두 용도로 쓰인다:
(a) **진행 중 작업 격리** — 부수 조사/탐색을 부모 컨텍스트 오염 없이 끝까지 실행.
(b) **plan-dev Phase 6 세션 클로저** — 작업이 이미 끝난 경우, 잔여 정리 + 세션 요약 + 다음 명령 추천만 수행(새 작업을 만들지 말 것).

진행 순서:
1. 필요한 조사 (Glob/Grep/Read, 필요 시 추가 서브에이전트 호출)
2. 접근 방식 결정
3. 실제 작업 실행 (파일 수정 포함)
4. 아래 형식으로 결과 반환

반드시 다음 형식을 따라라:

**결과 요약**
한 단락.

**변경된 파일**
- 경로:라인

**상태**: 완료 / 부분완료 / 실패

**다음 추천 명령**
작업 결과를 보고 한 줄로 추천하라:
- 작업이 완전히 끝나 새 일로 넘어갈 상황이면 → `/clear`
- 같은 맥락의 후속 작업이 이어진다면 → `/compact <남길 핵심 + 다음 방향>`
형식 예: ``추천: `/compact focus on auth migration, drop research notes` ``

중간 시도·실패·노이즈는 어느 섹션에도 포함하지 말 것.
