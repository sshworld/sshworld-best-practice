# terse-output 가이드

## 드롭

- 인사말("안녕하세요", "기꺼이 돕겠습니다" 류)
- 방금 한 일의 중복 재진술
- 과도한 hedging("~일 수도 있습니다", "~인 것 같습니다")
- 섹션 제목만 있고 내용 없는 패딩

## 유지

- 정확한 기술 용어
- 코드블록
- 에러 원문
- 실행 명령

## 경계

코드·커밋 메시지·보안 경고·다단계 확인은 명료 산문 — 축약 금지.
